📘 Chapter 7 – Data Structures (Summary)

7.1 Introduction

Computers primarily function as data manipulation systems. Data → processed into information → used in planning & decisions.

To ensure data is stored, accessed, and managed reliably, we use Data Structures. This chapter explains:
✔ What data structures are ✔ How data is represented ✔ Types of data structures ✔ Operations on data structures ✔ Stack data structure (LIFO)

7.2 Elementary Data Representation

Data representation is divided into:

  • Raw Data – basic facts.
  • Data Item – single unit of value with a data type.
  • Data Structure – a named collection of data items stored in a defined manner.

Data Type vs Data Structure

  • Data Type → defines valid values and operations.
  • Data Structure → actual storage & access method (physical implementation).

7.3 Different Data Structures

Two main categories:

  • Simple Data Structures (integers, floats, chars, booleans)
  • Compound Data Structures (linear + non-linear)

7.3.1 Linear Lists (Arrays)

  • Indexed by consecutive integers (0,1,2…n−1).
  • Python implements arrays using lists or NumPy.

7.3.2 Stacks (LIFO)

  • Insert/delete from top only.
  • Like plates stacked vertically.

7.3.3 Queues (FIFO)

  • Insert at rear, delete at front.
  • Like a line of people waiting.

7.3.4 Linked Lists

  • Nodes linked with reference pointers.
  • Node = INFO + NEXT pointer.
  • Can be singly or doubly linked.

7.3.5 Trees (Non-linear)

  • Hierarchical structure.
  • Top node → Root.
  • Bottom nodes → Leaves.

7.4 Operations on Data Structures

  • Insertion – add new data.
  • Deletion – remove data.
  • Searching – find an element.
  • Traversal – visit all elements.
  • Sorting – arrange in order.
  • Merging – combine two structures.

7.5 Stacks (LIFO Structure)

A Stack is a linear structure where all operations happen at the top.

  • PUSH – insert at top.
  • POP – remove from top.
  • PEEK – view top element.
  • Overflow – pushing to a full stack.
  • Underflow – popping from an empty stack.

7.5.1 Implementing Stack in Python

  • Push → stack.append(item)
  • Pop → stack.pop()
  • Peek → stack[-1]

7.5.2 Stack Applications

  • Reversing a line of text
  • Expression conversion (infix → postfix)
  • Expression evaluation (postfix / prefix)

Analogy

A stack works like a spring-loaded plate dispenser — the last plate you put is the first you take.
