📘 Chapter 7 – Data Structures (Detailed Summary)

7.1 Introduction

A computer system works primarily as a data manipulation system. Therefore, “Data” becomes a crucial component of computing. Data and information drive organizational planning, decision-making, and operations.

To support reliable data storage, processing, and management, Data Structures act as the backbone. This chapter first explains basic terminology and then focuses deeply on the Stack data structure.

7.2 Elementary Data Representation

Three forms of Data:

  • Raw Data – raw facts or simple values.
  • Data Item – single unit of value having a data type.
  • Data Structure – named group of data stored in specific manner.

Difference: Data Type vs Data Structure

  • Data Type: Defines valid values + allowed operations.
  • Data Structure: Actual physical arrangement, storing & accessing pattern.

Example: A Python list can behave like a stack where insertion/deletion happens only at one end.

7.3 Different Data Structures

Classification:

  • Simple Data Structures – built using primitive types (int, float, bool, char).
  • Compound Data Structures – built using simple structures.

Linear Data Structures

7.3.1 Arrays (Linear Lists)

  • Finite number of similar elements.
  • Indexed as 0,1,2…n−1.
  • Python implements arrays via Lists or NumPy arrays.

7.3.2 Stacks – LIFO

  • Insert/Delete only at top.
  • Example: stack of plates.

7.3.3 Queues – FIFO

  • Insert at rear, delete from front.
  • Example: line of people waiting.

7.3.4 Linked Lists

  • Nodes are connected using references (pointers).
  • Each node = INFO + NEXT.
  • Singly Linked vs Doubly Linked.

Non-Linear Data Structures

7.3.5 Trees

  • Hierarchical structure (root → leaves).
  • Each node stores references to children nodes.

7.4 Operations on Data Structures

  • Insertion – add new data.
  • Deletion – remove data.
  • Searching – locate an element.
  • Traversal – visit all elements.
  • Sorting – arrange in order.
  • Merging – combine two structures.

7.5 Stacks

A Stack follows the LIFO (Last In First Out) rule. All actions occur on the top.

Operations:

  • PUSH – add item to top.
  • POP – remove item from top.
  • Peek – view top element without removing.
  • Overflow – stack full, cannot push.
  • Underflow – stack empty, cannot pop.

Types of Stacks:

  • Dynamic – grows/shrinks.
  • Static – fixed size.

7.5.2 Stack Applications

7.5.2A Reversing a Line

Push characters → pop them → output reversed string.

7.5.2B Polish Strings

Stacks help convert & evaluate expressions:

  • Infix → A + B
  • Prefix → +AB
  • Postfix → AB+

Why Postfix?

No need to check precedence → machine friendly.

Evaluating Postfix:

  • Push operands
  • Pop operands when operator found
  • Compute + push result

Evaluating Prefix:

  • Uses two stacks: symbol stack + value stack.
