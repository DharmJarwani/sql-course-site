Q16. Explain any 4: (i) Hub (ii) Modem (iii) RJ-45 (iv) Repeater (v) Router
  • Hub — basic network device that broadcasts incoming frames to all ports (Layer-1).
  • Modem — converts digital <> analog signals for telephone/cable lines.
  • RJ-45 — connector used for Ethernet UTP cables.
  • Repeater — regenerates/boosts signal to extend cable range.
  • Router — forwards packets between networks and provides gateway functions.

Corrected & Completed Code: 
import csv

def addCsvFile(UserName, PassWord):
    # open file in append mode to add data
    f = open('user.csv','a', newline='')
    newFileWriter = csv.writer(f)
    newFileWriter.writerow([UserName, PassWord])
    f.close()

def readCsvFile():
    # read data from CSV file
    with open('user.csv','r') as newFile:
        newFileReader = csv.reader(newFile)
        for row in newFileReader:
            print(row[0], row[1])
    newFile.close()

addCsvFile("Arjun","123@456")
addCsvFile("Arunima","aru@nima")
addCsvFile("Frieda","myname@FRD")
readCsvFile()
