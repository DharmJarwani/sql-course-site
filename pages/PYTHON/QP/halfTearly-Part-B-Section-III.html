Q33. Indian Public School — four wings A (Admin), S (Senior), J (Junior), H (Hostel). Distances & machines given. Answer (i)-(v).
  1. (i) Server placement:
    Wing S (Senior) should host the server because it has the maximum computers (200). Placing the server here ensures most traffic stays local, reducing network congestion.
    Rule: Always choose the wing with the heaviest usage for server location.
  2. (ii) Suitable topology:
    A Star topology with Wing S as the core. Access switches are installed in Wings A, J, H and connected back to the core switch in Wing S.
    Advantage: Easy troubleshooting and expansion. Fiber or high-quality UTP can be used depending on the distance.
  3. (iii) Devices required:
    • Core switch in Wing S (high port capacity, possibly stackable).
    • Access switches in A, J, H sized by computers in each wing.
    • NICs for every PC.
    • Router + firewall at Wing S for Internet access and security.
    • Optional Wi-Fi access points for wireless coverage.
  4. (iv) Repeaters or alternatives:
    Distances like 400m (S↔H) and 450m (J↔H) exceed copper cable limits. Instead of simple repeaters, fiber optic cable or intermediate switches should be used. Fiber is recommended as it handles higher bandwidth and longer distances.
  5. (v) Type of network:
    All wings are inside the same school campus, so it is a LAN (Local Area Network). If these were different campuses in the same city, it would be a MAN. If in different cities, it would be a WAN.
Q34. Binary file Book.dat structure [BookNo, Book_Name, Author, Price].
(i) Write CreateFile() to add a record. (ii) Write CountRec(Author) to count books by that author.
OR: STUDENT.DAT (admission_number, Name, Percentage) — write countrec() to list students >75% and display count.
Solution using pickle for Book.dat: 
import pickle, os
BOOK_FILE = "Book.dat"

# (i) Function to add a new book record
def CreateFile():
    book_no = input("Enter BookNo: ").strip()
    book_name = input("Enter Book Name: ").strip()
    author = input("Enter Author: ").strip()
    price = float(input("Enter Price: ").strip() or 0)
    record = {"BookNo": book_no, "Book_Name": book_name,
              "Author": author, "Price": price}
    with open(BOOK_FILE, "ab") as f:
        pickle.dump(record, f)
    print("Record added successfully!")

# (ii) Function to count books by given author
def CountRec(author_name):
    cnt = 0
    if not os.path.exists(BOOK_FILE):
        return 0
    with open(BOOK_FILE, "rb") as f:
        while True:
            try:
                rec = pickle.load(f)
            except EOFError:
                break
            if rec.get("Author", "").strip().lower() == author_name.strip().lower():
                cnt += 1
    print("Total books by", author_name, ":", cnt)
    return cnt

OR (Student.dat version): 
import pickle, os
STUDENT_FILE = "STUDENT.DAT"

def countrec():
    if not os.path.exists(STUDENT_FILE):
        print("No data")
        return
    cnt = 0
    with open(STUDENT_FILE,"rb") as f:
        while True:
            try:
                rec = pickle.load(f)
            except EOFError:
                break
            if isinstance(rec, dict):   # if stored as dictionary
                adm = rec.get("admission_number")
                name = rec.get("Name")
                perc = float(rec.get("Percentage",0))
            else:   # if stored as tuple/list
                adm, name, perc = rec
                perc = float(perc)
            if perc > 75:
                print(adm, name, perc)
                cnt += 1
    print("Number of students scoring above 75%:", cnt)
