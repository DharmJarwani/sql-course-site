Question 1: What is the difference between “w” and “a” modes?
  • "w" mode: Opens the file for writing. If file already exists, it will overwrite its content.
  • "a" mode: Opens the file for appending. New data will be added at the end of the file, without removing existing content.
Question 2: What is the significance of a file-object?
A file-object is a Python variable that acts as a link between the program and the file on disk. It provides methods to read from or write to the file.
Question 3: How is open() function different from close() function?
  • open(): Used to open a file and returns the file-object.
  • close(): Used to close an open file and free system resources. It's good practice to close files after use.

Question 8: What role is played by file modes in file operations? Describe the various file mode constants and their meanings.
File modes define how a file will be opened — for reading, writing, appending, or in binary/text format.

Common File Modes:
  • 'r' – Read (default mode)
  • 'w' – Write (overwrites file)
  • 'a' – Append (writes at end of file)
  • 'rb' – Read binary file
  • 'wb' – Write binary file
  • 'r+' – Read and write
  • 'b' – Binary mode
  • 't' – Text mode (default)
Question 9: What are the advantages of saving data in:
  • (i) Binary form: Faster processing, less space, useful for complex data structures.
  • (ii) Text form: Human-readable, easy to edit and debug.
  • (iii) CSV files: Easy exchange of tabular data, supported by spreadsheets like Excel.
Question 10: When do you think text files should be preferred over binary files?
Text files are preferred when:
  • Data needs to be human-readable or easily edited.
  • File is to be shared with non-programmers or opened in tools like Notepad or Excel.
  • Application does not require high speed or compact storage.

Question 14: Is CSV file different from a text file? Why/Why not?
Answer: A CSV file is a type of text file where data is stored in comma-separated format.
Difference: While both are text files, CSV has a specific structure for tabular data, making it easier to parse rows and columns.
Question 15: Is CSV file different from binary file? Why/Why not?
Answer: Yes, CSV files are text-based, whereas binary files contain non-text (encoded) data.
Difference: CSV is readable in editors like Notepad, binary files require a program to decode and interpret the data.
Question 16: Why are CSV files popular for data storage?
Answer: CSV files are simple, human-readable, and supported by almost all data tools (Excel, databases, etc.).
They store data in a structured, tabular format and are lightweight and easy to parse programmatically.
Question 17: How do you change the delimiter of a CSV file while writing into it?
Answer: Use the delimiter parameter of the csv.writer() function.

writer = csv.writer(file, delimiter=';')
Question 18: When and why should you suppress the EOL translation in CSV file handling?
Answer: While writing to CSV on Windows, use newline='' in open() to avoid extra blank lines.
Example: open('file.csv', 'w', newline='')
This suppresses the default translation of line endings.
Question 19: If you rename a text file’s extension as .csv, will it become a CSV file? Why/Why not?
Answer: No. Changing the extension does not convert the file format.
For a file to be a valid CSV, it must contain properly formatted comma-separated values.
