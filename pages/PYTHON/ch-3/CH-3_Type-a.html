Question 1: A program having multiple functions is considered better designed than a program without any function. Why?
Functions improve readability, reduce repetition, enable reuse, simplify debugging, and allow modular programming. They make the code more organized and easier to maintain.
Question 2: What all information does a function header give you about the function?
A function header provides the function name, parameters, and optional default values. It tells how the function is called and what input it expects. 

def greet(name="Guest"):
    ...
Question 3: What do you understand by flow of execution?
Flow of execution is the order in which the Python interpreter executes statements. In a function call, it jumps into the function, executes its code, and returns to the caller.
Question 4: What are arguments? What are parameters? How are these two terms different yet related? Give example.
Parameters are variables in the function definition. Arguments are actual values passed to the function.

Example: 

def greet(name):   # name is a parameter
    print("Hello", name)

greet("Alice")     # "Alice" is an argument
Question 5: What is the utility of: (i) default arguments, (ii) keyword arguments?
  • Default arguments: Allow functions to be called with fewer arguments.
  • Keyword arguments: Improve readability and allow arguments in any order.
Question 6: Explain with a code example the usage of default arguments and keyword arguments.

def info(name, age=18):
    print(name, "is", age, "years old")

info("Raj")                  # Uses default age
info(name="Simran", age=22)  # Keyword arguments
Question 7: Describe the different styles of functions in Python using appropriate examples.
  • Built-in Functions: Predefined in Python (e.g., len(), max())
  • User-defined Functions: Defined using def keyword
  • Lambda Functions: Anonymous functions using lambda keyword

Question 8: Differentiate between fruitful functions and non-fruitful functions.
  • Fruitful Functions: Return a value using return statement.
  • Non-fruitful Functions: Perform an action but return nothing.

def add(x, y): return x + y    # Fruitful
def greet(): print("Hi!")      # Non-fruitful
Question 9: Can a function return multiple values? How?
Yes, Python functions can return multiple values using comma-separated values which form a tuple. 

def calc(x, y):
    return x + y, x * y

sum_, product = calc(5, 3)
Question 10: What is scope? What is the scope resolving rule of Python?
Scope defines the visibility of variables. Python uses the LEGB rule:
Local → Enclosing → Global → Built-in.
Python checks variables in this order to resolve references.
Question 11: What is the difference between local and global variables?
  • Local Variable: Declared inside a function and accessible only within it.
  • Global Variable: Declared outside all functions and accessible throughout the program.

x = 10  # Global

def show():
    x = 5  # Local
    print("Local x:", x)

show()
print("Global x:", x)
Question 12: When is global statement used? Why is its use not recommended?
The global statement is used inside a function to modify a global variable.
Not recommended because it can make code harder to debug, breaks modularity, and may introduce side-effects. 

x = 10

def modify():
    global x
    x = 20

modify()
print(x)  # 20
Question 13: Write the term suitable for following descriptions:
  • (a) A name inside the parentheses of a function header that can receive a value.
    Answer: Parameter
  • (b) An argument passed to a specific parameter using the parameter name.
    Answer: Keyword Argument
  • (c) A value passed to a function parameter.
    Answer: Argument
  • (d) A value assigned to a parameter name in the function header.
    Answer: Default Value
  • (e) A value assigned to a parameter name in the function call.
    Answer: Keyword Argument
  • (f) A name defined outside all function definitions.
    Answer: Global Variable
  • (g) A variable created inside a function body.
    Answer: Local Variable
Question 14: What do you understand by local and global scope of variables? How can you access a global variable inside the function, if function has a variable with same name?
  • Local Scope: Variables accessible only within a function.
  • Global Scope: Variables accessible throughout the program.
If a local variable has the same name, the global variable can be accessed using the global keyword or by using modules like globals(): 

x = 100  # Global

def func():
    x = 50  # Local shadows global
    print("Local:", x)
    print("Global using globals():", globals()['x'])

func()
