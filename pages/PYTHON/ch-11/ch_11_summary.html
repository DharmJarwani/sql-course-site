📘 Chapter 11 – Simple Queries in SQL (Detailed Summary)

11.1 Introduction

  • SQL (Structured Query Language), jise SEQUEL bhi kehte hain, 1970s mein IBM lab mein develop hua.
  • SQL ek 4th generation non-procedural language hai.
  • Non-procedural language → Hum batate hain “WHAT to do”, na ki “HOW to do”.
  • SQL allow karta hai:
    • Database structure create/modify karna
    • Security settings change karna
    • User permissions dena
    • Data query karna
    • Insert/Modify/Delete

11.2 Some MySQL SQL Elements

11.2.1 Literals
  • Character Literals quotes (' ') ya (" ") mein hote hain.
  • Apostrophe ke liye escape: \'
  • Numeric Literals quotes me nahi hote (22, 1997). Up to 53 digits precision.
11.2.2 Data Types
  • Numeric Types: INT, TINYINT, SMALLINT, BIGINT, FLOAT, DOUBLE, DECIMAL
  • Date & Time: DATE, DATETIME, TIMESTAMP, TIME, YEAR
  • String Types: CHAR, VARCHAR, BLOB, TEXT, ENUM
11.2.3 Null Values
  • NULL ≠ 0
  • Arithmetic with NULL → result NULL
11.2.4 Comments
  • Multi-line: /* ... */
  • Single-line: -- comment or # comment

11.3 SQL Command Syntax

  • Statements semicolon ; se end hote hain.
  • SQL keywords case-sensitive nahi hote.
  • Syntax symbols:
    • { } → OR
    • [ ] → optional
    • ... → repetitions
    • <> → special terms

11.4 Sample Database

  • Database load: SOURCE path/filename.sql;
  • Tables list: SHOW TABLES;

11.5 Making Simple Queries

11.5.1 Creating & Accessing Database
  • Create: CREATE DATABASE dbname;
  • Access: USE dbname;
11.5.2 SELECT Command
  • Basic syntax: SELECT col1, col2 FROM table;
  • Column order = SELECT list order
11.5.3 Selecting All Columns
  • SELECT * FROM table;
11.5.5 DISTINCT
  • Duplicate rows remove karta hai.
  • NULL values → only one returned.
11.5.6 ALL
  • Duplicates retain karta hai.
  • Default behaviour.
11.5.7 Viewing Structure
  • DESCRIBE table; or DESC table;
11.5.8 Calculations
  • SELECT 1 + 6;
  • SELECT 4 * 3 FROM dual;
11.5.9 Scalar Expressions
  • SELECT comm * 100 FROM emp;
  • NULL in expression → NULL result
11.5.10 Column Aliases
  • SELECT ename AS 'Employee Name' FROM emp;
11.5.11 Handling Nulls
  • IFNULL(col, value)
11.5.12 Text in Output
  • SELECT ename, 'Good Employee' FROM emp;
11.5.13 WHERE Clause
  • Filters rows based on conditions.
11.5.14 Relational Operators
  • =, >, <, >=, <=, <>
  • Character/Date values → in quotes
11.5.15 Logical Operators
  • AND, OR, NOT
  • Priority: NOT → AND → OR
11.5.16 BETWEEN
  • Range inclusive
  • NOT BETWEEN opposite
11.5.17 IN
  • IN ( ) list match
  • NOT IN = list exclude
11.5.18 LIKE
  • Pattern matching
  • % → any substring
  • _ → single character
11.5.19 Searching NULL
  • IS NULL / IS NOT NULL
11.5.20 Operator Precedence
  • Unary → * / % → Comparison → NOT → AND → OR
11.5.21 ORDER BY
  • Default ASC
  • DESC for descending
  • Multiple columns allowed

11.6 MySQL Functions

11.6.1 String Functions
  • CHAR(), CONCAT(), LOWER(), UPPER(), SUBSTRING(), TRIM(), LENGTH()
11.6.2 Numeric Functions
  • MOD(), POWER(), ROUND(), TRUNCATE()
11.6.3 Date & Time Functions
  • CURDATE(), DATE(), MONTH(), YEAR()
  • NOW() → start time
  • SYSDATE() → actual execution time

11.7 Aggregate Functions

  • Grouped rows par operate hote hain.
  • NULLs ignored (except COUNT(*))
  • Functions:
    • AVG() – average
    • COUNT() – row count
    • MAX() / MIN()
    • SUM()
Analogy:
SQL ek librarian ki tarah kaam karta hai. Aap SELECT ke through bolte ho “Mujhe kaun se books chahiye?”, WHERE = filtering section, ORDER BY = sorting shelves, FUNCTIONS = librarian ki utilities (calculator, search light).
