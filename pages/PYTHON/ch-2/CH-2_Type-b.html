Question 5: Find the errors. State reasons.

(a) Tuple is immutable
t = (1, "a", 9.2)
t[0] = 6    # ❌ Error

Reason: Tuples are immutable, meaning their elements cannot be changed once defined.

Fix: Use a list if you need to update values.

t = [1, "a", 9.2]
t[0] = 6    # ✅ Works correctly
(b) Repetition of part (a)
t = (1, "a", 9.2)
t[0] = 6    # ❌ Error again

Reason: Same as part (a) — trying to modify a tuple element.

(c) Index out of range in tuple
t = (1, "a", 9.2)
t[4] = 6    # ❌ Error

Reason: Tuple has only 3 elements (index 0 to 2), so index 4 does not exist.

Note: Even if index existed, it would still be an error since tuples are immutable.

(d) Strings are immutable
t = 'hello'
t[0] = 'H'    # ❌ Error

Reason: Strings in Python are immutable. You cannot assign to a character position.

Fix: Reconstruct the string instead.

t = 'hello'
t = 'H' + t[1:]   # ✅ New string with 'H' at start
(e) Multiple syntax errors in loop and condition
for Name in [Amar, Shveta, Parag]:
    If Name[0] = 'S':
        print(Name)     # ❌ Multiple Errors

Errors:

  • Strings must be enclosed in quotes (e.g. "Amar")
  • If should be lowercase → if
  • = is an assignment operator, use == for comparison

Correct version:

for Name in ["Amar", "Shveta", "Parag"]:
    if Name[0] == 'S':
        print(Name)

Question 6: Error in list reversal loop

Assuming words is a valid list of words, the program below tries to print the list in reverse. Does it have an error? If so, why?

Code: 
for i in range(Ien(words), 0, -1):
    print(words[1], end-’ ‘ )

Yes, there are two errors:

  1. Typo in function name: Ien should be len (lowercase L).
  2. Wrong indexing: words[1] always prints the second word repeatedly. It should be words[i - 1] because range is from length to 1 (exclusive).
  3. Syntax error: end-’ ‘ is invalid. Use end=' '.

Corrected version:

for i in range(len(words), 0, -1):
    print(words[i - 1], end=' ')

Question 9: Predict the Output

Question 11: List Element Formatter

Write a method in Python to display the elements of list thrice if it is a number and display the element terminated with ‘#’ if it is not a number.

Example Input:
List = [‘42’, ‘DROND’, ‘GIRIRAJ’, ‘13’, ‘ZARA’]
Expected Output:
424242
DROND#
GIRIRAJ#
131313
ZARA#
def display_elements(lst):
    for item in lst:
        if item.isdigit():
            print(item * 3)
        else:
            print(item + '#')

# Sample usage
List = ['42', 'DROND', 'GIRIRAJ', '13', 'ZARA']
display_elements(List)

Explanation:

  • isdigit() checks if the string contains only digits.
  • If true, the number string is repeated 3 times using item * 3.
  • If not a number, # is appended to the word.

Output:

424242
DROND#
GIRIRAJ#
131313
ZARA#
