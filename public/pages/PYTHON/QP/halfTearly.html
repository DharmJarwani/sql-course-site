Q8. Name the built-in function that returns absolute value.
Answer: abs()

Q16. Explain any 4: (i) Hub (ii) Modem (iii) RJ-45 (iv) Repeater (v) Router
  • Hub — basic network device that broadcasts incoming frames to all ports (Layer-1).
  • Modem — converts digital <> analog signals for telephone/cable lines.
  • RJ-45 — connector used for Ethernet UTP cables.
  • Repeater — regenerates/boosts signal to extend cable range.
  • Router — forwards packets between networks and provides gateway functions.

Q28. Write function LShift(Arr,n) that left-shifts a list by n. Example: Arr=[10,20,30,40,12,11], n=2 → Output: [30,40,12,11,10,20]
Example function: 
def LShift(Arr, n):
    n = n % len(Arr)
    return Arr[n:] + Arr[:n]

print(LShift([10,20,30,40,12,11], 2))  # [30,40,12,11,10,20]
Q29. (a) Write function to count occurrence of "Me" or "My" in STORY.TXT. Example result: Count = 4.
OR (b) Write AMCount() to count letters A/a and M/m.
(a) Count "Me"/"My" — simple approach: 
def count_me_my(filename="STORY.TXT"):
    count = 0
    with open(filename,"r") as f:
        for line in f:
            words = [w.strip(".,!?;:") for w in line.split()]
            for w in words:
                if w == "Me" or w == "My":
                    count += 1
    print("Count of Me/My in file:", count)
(b) AMCount() example: 
def AMCount(filename="STORY.TXT"):
    A = M = 0
    with open(filename,"r") as f:
        text = f.read()
    for ch in text:
        if ch == 'A' or ch == 'a': A += 1
        if ch == 'M' or ch == 'm': M += 1
    print("A or a :", A)
    print("M or m :", M)
Q30. DISPLAYWORDS() — read lines from story.txt and display words with length < 4.
def DISPLAYWORDS(filename="story.txt"):
    with open(filename,"r") as f:
        for line in f:
            for w in line.split():
                if len(w.strip(".,!?;:")) < 4:
                    print(w.strip(".,!?;:"))

Q32. MyPace University network planning. Data (distances & computers) given earlier. Answer the five sub-parts (i)-(v).
  1. (i) Server location: HR Center — it has the largest number of computers (115) so centralizing there minimizes traffic for most users.
  2. (ii) Topology: Star topology with a core switch in HR and access switches in each block; fiber/UTP links to each block.
  3. (iii) Devices: Managed Ethernet switches in each block sized to number of hosts (HR: 48-port stacks, Technology: 48/24, Business/Law: 24-port). NICs on all PCs; router/firewall at core.
  4. (iv) Repeater placement: Longest copper run Law↔HR = 105 m > 100m limit — place an intermediate switch/repeater or use fiber between Law and HR to avoid exceeding 100 m.
  5. (v) Type of network to connect distant admission office (1250 km): WAN — distances beyond a campus require WAN technologies (leased line/MPLS/VPN).
Q33. Indian Public School — four wings A (Admin), S (Senior), J (Junior), H (Hostel). Distances & machines given. Answer (i)-(v).
  1. (i) Server placement: Wing S (Senior) — it has the most computers (200).
  2. (ii) Topology/layout: Star with a core in Wing S and access switches in A, J, H. Use fiber backbone or high-quality UTP between wings.
  3. (iii) Devices: Managed access switches in each wing (port count by host count), core switch + router/firewall in Wing S, NICs on PCs, optional Wi-Fi APs.

Q34. Binary file Book.dat structure [BookNo, Book_Name, Author, Price]. (i) Write CreateFile() to add a record. (ii) Write CountRec(Author) to count books by that author.
OR: STUDENT.DAT (admission_number, Name, Percentage) — write countrec() to list students >75% and display count.
Solution (Book.dat example using pickle): 
import pickle, os
BOOK_FILE = "Book.dat"

def CreateFile():
    book_no = input("Enter BookNo: ").strip()
    book_name = input("Enter Book Name: ").strip()
    author = input("Enter Author: ").strip()
    price = float(input("Enter Price: ").strip() or 0)
    record = {"BookNo":book_no,"Book_Name":book_name,"Author":author,"Price":price}
    with open(BOOK_FILE,"ab") as f:
        pickle.dump(record,f)

def CountRec(author_name):
    cnt = 0
    if not os.path.exists(BOOK_FILE):
        return 0
    with open(BOOK_FILE,"rb") as f:
        while True:
            try:
                rec = pickle.load(f)
            except EOFError:
                break
            if rec.get("Author","").strip().lower() == author_name.strip().lower():
                cnt += 1
    return cnt

import pickle, os
STUDENT_FILE = "STUDENT.DAT"

def countrec():
    if not os.path.exists(STUDENT_FILE):
        print("No data")
        return
    cnt = 0
    with open(STUDENT_FILE,"rb") as f:
        while True:
            try:
                rec = pickle.load(f)
            except EOFError:
                break
            # accept tuple or dict
            if isinstance(rec, dict):
                perc = float(rec.get("Percentage",0))
                adm = rec.get("admission_number"); name = rec.get("Name")
            else:
                adm,name,perc = rec
                perc = float(perc)
            if perc > 75:
                print(adm, name, perc)
                cnt += 1
    print("Number of students scoring above 75%:", cnt)
