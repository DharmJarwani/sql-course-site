Q8. Name the built-in function that returns absolute value.
Answer: abs()
Definition: The abs() function in Python returns the absolute value of a number. For integers and floats, it removes the negative sign if present. For complex numbers, it returns the magnitude.

Example:

print(abs(-7))     # Output: 7
print(abs(-3.14))  # Output: 3.14
print(abs(3+4j))   # Output: 5.0
