Q28. Write function LShift(Arr,n) that left-shifts a list by n. Example: Arr=[10,20,30,40,12,11], n=2 → Output: [30,40,12,11,10,20]
Example function: 
def LShift(Arr, n):
    n = n % len(Arr)
    return Arr[n:] + Arr[:n]

print(LShift([10,20,30,40,12,11], 2))  # [30,40,12,11,10,20]
Q29. (a) Write function to count occurrence of "Me" or "My" in STORY.TXT. Example result: Count = 4.
OR (b) Write AMCount() to count letters A/a and M/m.
(a) Count "Me"/"My" — function: 
def count_me_my(filename="STORY.TXT"):
    count = 0
    with open(filename, "r") as f:
        for line in f:
            # Split line into words and remove punctuation
            words = [w.strip(".,!?;:") for w in line.split()]
            for w in words:
                if w == "Me" or w == "My":   # check exact matches
                    count += 1
    print("Count of Me/My in file:", count)
How it works: • Opens STORY.TXT for reading. • Reads each line, splits into words, removes punctuation. • Counts only exact words Me or My. • Prints total count. Sample Input (STORY.TXT): 
My friend told me: "Trust Me."
I said, "My choice, My decision."
Sample Output: 
Count of Me/My in file: 4
(b) AMCount() function: 
def AMCount(filename="STORY.TXT"):
    A = M = 0
    with open(filename, "r") as f:
        text = f.read()
    for ch in text:
        if ch == 'A' or ch == 'a':
            A += 1
        if ch == 'M' or ch == 'm':
            M += 1
    print("A or a:", A)
    print("M or m:", M)
How it works: • Opens STORY.TXT, reads all text. • Goes through each character. • Increments counters when character is A/a or M/m. • Prints final totals. Sample Input (STORY.TXT): 
My Aim is Amazing.
Many are Around me.
Sample Output: 
A or a: 6
M or m: 4
Q30. DISPLAYWORDS() — read lines from story.txt and display words with length < 4.
Function code: 
def DISPLAYWORDS(filename="story.txt"):
    with open(filename, "r") as f:
        for line in f:
            for w in line.split():
                # Remove punctuation before checking length
                clean_word = w.strip(".,!?;:")
                if len(clean_word) < 4:
                    print(clean_word)
How it works: • Opens story.txt for reading. • Splits each line into words. • Strips punctuation like .,!?;: from each word. • Prints only words shorter than 4 characters. Sample Input (story.txt):

Q31. Write PUSH(Arr) — push numbers divisible by 5 into a stack (list) and display or show error if none.
Function code: 
def PUSH(Arr):
    stack = []
    for n in Arr:
        if n % 5 == 0:       # Only numbers divisible by 5
            stack.append(n)
    if stack:
        print("Stack:", stack)
    else:
        print("Error: No element divisible by 5")
How it works: • Takes a list Arr as input. • Iterates through each element. • If number is divisible by 5, it is appended (pushed) into the stack. • After loop, displays stack or error if empty. Sample Input: 
PUSH([12, 15, 22, 40, 9, 55])
Sample Output: 
Stack: [15, 40, 55]
Another Input: 
PUSH([3, 7, 11])
Output: 
Error: No element divisible by 5
