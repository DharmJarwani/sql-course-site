Q18. Evaluate expressions:
(i) 6 * 3 + 4**2 // 5 - 8
(ii) 10 > 5 and 7 > 12 or not 18 > 3
  • (i) Step-by-step:
    • Expression: 6 * 3 + 4**2 // 5 - 8
    • Exponent first: 4**2 = 16
    • Floor division: 16 // 5 = 3
    • Multiplication: 6 * 3 = 18
    • Now: 18 + 3 - 8
    • Addition & subtraction: 21 - 8 = 13
    Final Answer: 13
  • (ii) Step-by-step:
    • Expression: 10 > 5 and 7 > 12 or not 18 > 3
    • Compare: 10 > 5 → True, 7 > 12 → False
    • Evaluate True and False = False
    • Compare: 18 > 3 → True
    • Apply not True = False
    • Now: False or False = False
    Final Answer: False
Q19. Differentiate between Ethernet card and WiFi card. OR between Web server and Web browser + name two browsers.
Ethernet card: wired NIC for UTP/RJ45. WiFi card: wireless NIC using radio.

Web server: stores and serves web pages (e.g., Apache, IIS). Web browser: client program to access web pages (e.g., Chrome, Firefox).

Q21. Differentiate between actual (actual parameter) and formal parameters with example. OR explain global keyword with example.
Actual parameter — the value passed during a call. Formal parameter — the variable defined in the function signature that receives the value.
def add(x,y):   # x,y formal parameters
    return x+y

add(3,4)          # 3,4 are actual parameters

global example: 
count = 0
def inc():
    global count
    count += 1

Q26. Give postfix form for: NOT A OR NOT B NOT C
Step-by-step Explanation:
  1. Original expression is written as: NOT A OR NOT B NOT C
  2. This is ambiguous, but usually interpreted as:
    (NOT A) OR ((NOT B) AND (NOT C))
  3. Step 1: Write inner parts:
    • NOT A → A'
    • NOT B → B'
    • NOT C → C'
  4. Step 2: Combine B' and C' with AND → B' C' AND
  5. Step 3: Now expression becomes:
    A' OR (B' C' AND)
  6. Step 4: Final postfix:
    A' B' C' AND OR
Final Answer (Postfix form): A' B' C' AND OR

            m = m + str[i].upper()
