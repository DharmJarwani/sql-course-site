Chapter 3 Functions

Q1. Write a function that takes amount-in-dollars and dollar-to-rupee conversion rate, and returns the amount in rupees. Implement both a void (prints) and a non-void (returns) function.
Level 1 — Conceptual Flow

First create variables for the dollar amount and conversion rate. Then write one function that returns the converted amount and another function that prints the converted amount. Call both functions from the main program.

Level 2 — Step-by-step
  1. Create two variables: dollars and rate.
  2. Define a void function: print_rupees(dollars, rate) that prints dollars * rate.
  3. Define a non-void function: convert_to_rupees(dollars, rate) that returns dollars * rate.
  4. Call convert_to_rupees, store the result and print it. Then call print_rupees directly.
