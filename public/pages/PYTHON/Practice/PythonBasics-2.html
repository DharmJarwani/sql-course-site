< , > Operators + Python Alignment Explained
Q1. Use < (less than) operator. 

print(2 < 5)   # True
print(10 < 3)  # False
print(7 < 7)   # False
Explanation:
  • < checks if left value is smaller.
  • 2 is smaller than 5 → True.
  • 10 smaller than 3 → False.
  • Equal values: 7 < 7 → False.
Q2. Use > (greater than) operator. 

print(9 > 4)   # True
print(3 > 6)   # False
print(8 > 8)   # False
Explanation:
  • > checks if left value is larger.
  • 9 > 4 → True.
  • 3 > 6 → False.
  • Equal values → False.
Q3. Use <=. 

print(5 <= 5)  # True
print(2 <= 9)  # True
print(7 <= 3)  # False
Explanation:
  • Works for smaller or equal values.
Q4. Use >=. 

print(8 >= 3)  # True
print(4 >= 4)  # True
print(1 >= 9)  # False
Explanation:
  • Larger or equal → True.
Q5. In f-string formatting < means LEFT-ALIGN (not less-than). 

# Left Align (<)
print(f"{'Amit':<10}Hello")

# Right Align (>)
print(f"{'Amit':>10}Hello")

# Center (^)
print(f"{'Amit':^10}Hello")
Explanation:
  • < → Left align inside fixed width.
  • > → Right align inside fixed width.
  • ^ → Center align.
  • Ye comparison operator nahi — sirf formatting symbol hai.
Q6. Both concepts together. 

age = 18
print(age < 21)   # comparison -> True

name = "Ravi"
print(f"{name:<10}Allowed")   # formatting -> Ravi______Allowed
Explanation: Comparison (<) checks values. Formatting (<) aligns text.
