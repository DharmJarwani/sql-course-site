True / False Comparison Examples
Q1. Compare two integers using == and print True or False. 

a = 10
b = 10

print(a == b)   # True
Explanation:
  • a and b both hold value 10.
  • a == b checks if values are equal.
  • Since 10 equals 10, the result is True.
Q2. Compare two strings using ==. 

s1 = "apple"
s2 = "apple"

print(s1 == s2)   # True
Explanation:
  • Both strings contain the same characters.
  • "apple" == "apple" gives True.
  • String comparison checks each character.
Q3. Compare two float numbers using ==. 

x = 3.5
y = 4.2

print(x == y)    # False
Explanation:
  • x is 3.5 and y is 4.2.
  • Values do not match, so result is False.
Q4. Compare two boolean values using ==. 

flag1 = True
flag2 = False

print(flag1 == flag2)   # False
Explanation:
  • True is not equal to False.
  • So comparison gives False.
Q5. Compare two lists using ==. 

list1 = [1, 2, 3]
list2 = [1, 2, 3]

print(list1 == list2)   # True
Explanation:
  • Both lists have the same elements in the same order.
  • List comparison checks both values and order.
  • Since they match, output is True.
