Question 1: What is the significance of Modules?
Modules allow you to organize Python code into reusable parts. They help in better code management, reduce redundancy, and make debugging easier by dividing logic into separate files.
Question 2: What are docstrings? What is their significance? Give example to support your answer.
Docstrings are special strings used to document a function, class, or module. They help others understand what your code does. 

def greet(name):
    """This function greets the user by name."""
    print("Hello", name)

Significance: You can access docstrings using help().

Question 3: What is a package? How is a package different from module?
A package is a collection of related modules stored in a directory with an __init__.py file.
Module: Single file (.py)
Package: Folder with multiple modules
Question 4: What is a library? Write procedure to create own library in Python.
A library is a collection of useful modules and packages.

Steps to create your own library:
  • Create a folder (your library)
  • Add your Python files (modules)
  • Add __init__.py file (even if empty)
  • Use import to use it in programs
Question 5: What is the use of file __init__.py in a package even when it is empty?
__init__.py tells Python that the folder should be treated as a package. Without it, the package cannot be imported.
Question 6: What is the importance of site-packages folder of Python installation?
The site-packages folder contains third-party libraries and packages installed using pip. Python checks this folder while importing modules.
Question 7: How are following import statements different?
  • import X – Imports entire module. Use with X.function().
  • from X import * – Imports all functions and variables directly.
  • from X import a, b, c – Imports only selected functions or variables from module.
Question 8: What is PYTHONPATH variable? What is its significance?
PYTHONPATH is an environment variable that tells Python where to find modules and packages other than the default ones.
Question 9: In which order Python looks for the function/module names used by you?
Python looks in the following order:
  1. Local scope (inside function)
  2. Enclosing scope (outer functions)
  3. Global scope (main script)
  4. Built-in scope (default Python functions)
This is known as the LEGB rule.
Question 10: What is the usage of help() and dir() functions.
  • help(object) – Shows documentation and usage of object/module
  • dir(object) – Lists all attributes and methods of an object/module

import math
help(math)
dir(math)

Question 13: What is dot notation of referring to objects inside a module?
Dot notation refers to accessing attributes, functions, or objects from a module using the syntax: module_name.object_name

Example: 

import math
print(math.sqrt(16))
Question 14: Why should the from module import object statement be avoided to import objects?
It can cause name conflicts if different modules have objects with the same name. It also reduces readability as it’s unclear which module the object belongs to.
Question 15: What do you understand by standard library of Python?
The standard library is a collection of built-in modules and packages that come with Python. It provides many useful functions like math, random, datetime, os, etc., without needing to install anything extra.
Question 16: Explain the difference between import module and from module import statements, with examples.
  • import module: You access objects using module name.
    • 
import math
print(math.sqrt(25))
  • from module import object: You access objects directly.
    • 
from math import sqrt
print(sqrt(25))
Note: The second form is shorter, but may cause name conflicts.
