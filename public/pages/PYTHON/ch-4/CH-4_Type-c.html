Q1. Write a Python program having the following functions:

(i) A function with the following signature:
remove_letter(sentence, letter)
This function should take a string and a letter (as a single-character string) as arguments, returning a copy of that string with every instance of the indicated letter removed.

(ii) A function that implements capwords() functionality using split(), capitalize(), and join(). Then compare the result with string.capwords() from the Python standard library. 

# (i) Remove all instances of a letter using split() + join()
def remove_letter(sentence, letter):
    return ''.join(sentence.split(letter))

# Example usage
print(remove_letter("Hello there!", "e"))  # Output: Hllo thr!


# (ii) Capitalize each word (simulate capwords)
def custom_capwords(text):
    words = text.split()
    capitalized_words = [w.capitalize() for w in words]
    return ' '.join(capitalized_words)

# Compare with built-in capwords from string module
import string
text = "python is amazing"
print(custom_capwords(text))        # Output: Python Is Amazing
print(string.capwords(text))        # Output: Python Is Amazing
Explanation:
  • remove_letter():
    • Uses split(letter) to break the string around the given letter.
    • Then join() merges all pieces back, excluding that letter.
  • custom_capwords():
    • Breaks sentence into words using split()
    • Capitalizes each using capitalize()
    • Joins them back into a single string with join()
  • Result is compared with string.capwords() to ensure same behavior.
Q2. Create a module lengthconversion.py that stores functions for various lengths conversion like:
  • miletokm()
  • kmtomile()
  • feettoinches()
  • inchestofeet()
It should also store constants like:
1 mile = 1.609344 km and 1 foot = 12 inches
Add a help() function to display usage info. 

# lengthconversion.py

# --- Constants ---
MILE_TO_KM = 1.609344
KM_TO_MILE = 1 / MILE_TO_KM
FEET_TO_INCH = 12
INCH_TO_FEET = 1 / FEET_TO_INCH

# --- Conversion Functions ---
def miletokm(miles):
    return miles * MILE_TO_KM

def kmtomile(km):
    return km * KM_TO_MILE

def feettoinches(feet):
    return feet * FEET_TO_INCH

def inchestofeet(inches):
    return inches * INCH_TO_FEET

# --- Help Function ---
def help():
    print("Available functions in lengthconversion module:")
    print("1. miletokm(miles)         → Convert miles to kilometers")
    print("2. kmtomile(km)            → Convert kilometers to miles")
    print("3. feettoinches(feet)      → Convert feet to inches")
    print("4. inchestofeet(inches)    → Convert inches to feet")
    print("\nConstants used:")
    print("1 mile = 1.609344 km, 1 foot = 12 inches")
Explanation:
  • miletokm and kmtomile use constant values to convert between miles and kilometers.
  • feettoinches and inchestofeet handle conversion using multiplication/division by 12.
  • The help() function prints friendly documentation for user assistance.
Q3. Create a module MassConversion.py that stores functions for:
  • kgtotonne() → kg to tonnes
  • tonnetokg() → tonnes to kg
  • kgtopound() → kg to pound
  • poundtokg() → pound to kg
Use constants: 1 kg = 0.001 tonne, 1 kg = 2.20462 pound. Also include a help() function that displays module info. 

# MassConversion.py

# --- Constants ---
KG_TO_TONNE = 0.001
TONNE_TO_KG = 1 / KG_TO_TONNE

def tonnetokg(tonne):
    return tonne * TONNE_TO_KG

def kgtopound(kg):
    return kg * KG_TO_POUND

def poundtokg(pound):

# --- Help Function ---
def help():
    print("Available functions in MassConversion module:")
    print("1. kgtotonne(kg)        → Convert kilograms to tonnes")
    print("2. tonnetokg(tonne)     → Convert tonnes to kilograms")
    print("3. kgtopound(kg)        → Convert kilograms to pounds")
    print("4. poundtokg(pound)     → Convert pounds to kilograms")
    print("\nConstants used:")
    print("1 kg = 0.001 tonne")
    print("1 kg = 2.20462 pound")
Explanation:
  • Constants are defined at the top for unit conversions.
  • Each function performs a simple calculation using the constants.
  • help() acts like documentation, describing usage.
Q4. Create a Python package with the following structure: 
Conversion/  
│  
├── Length/  
│   ├── __init__.py  
│   └── Lengthconversion.py  
│  
└── Mass/  
    ├── __init__.py  
    └── Massconversion.py
Make sure this directory structure qualifies as a Python package. You should be able to import the modules using standard import syntax. 

# Directory structure:
# Conversion/
# ├── Length/
# │   ├── __init__.py
# │   └── Lengthconversion.py
# └── Mass/
#     ├── __init__.py
#     └── Massconversion.py

# Sample contents of Lengthconversion.py
MILE_TO_KM = 1.609344
KM_TO_MILE = 1 / MILE_TO_KM
FEET_TO_INCHES = 12
INCHES_TO_FEET = 1 / FEET_TO_INCHES

def miletokm(mile):
    return mile * MILE_TO_KM

def kmtomile(km):
    return km * KM_TO_MILE

def feettoinches(feet):
    return feet * FEET_TO_INCHES

def inchestofeet(inch):
    return inch * INCHES_TO_FEET

def help():
    print("Length Conversion Module:\n- miletokm\n- kmtomile\n- feettoinches\n- inchestofeet")

# Sample contents of Massconversion.py
KG_TO_TONNE = 0.001
TONNE_TO_KG = 1 / KG_TO_TONNE
KG_TO_POUND = 2.20462
POUND_TO_KG = 1 / KG_TO_POUND

Explanation:
  • To make a directory a Python package, include an __init__.py file (can be empty).
  • The directory structure separates Length and Mass conversions into distinct modules.

from Conversion.Mass.Massconversion import kgtopound

  • This structure promotes modular code and easy maintenance.
