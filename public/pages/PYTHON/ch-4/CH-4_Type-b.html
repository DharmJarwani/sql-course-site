Question 1:

Create module tempConversion.py as given in Fig 4.2 in the chapter.

If you invoke the module with two different types of import statements, how would the function call statement for imported module's functions be affected?

Answer:

If tempConversion.py contains the following function:

def celsius_to_fahrenheit(c):
    return 9 * c / 5 + 32

Then depending on the type of import, function call changes:

  • Using: import tempConversion
    Call: tempConversion.celsius_to_fahrenheit(30)
  • Using: from tempConversion import celsius_to_fahrenheit
    Call: celsius_to_fahrenheit(30)

Conclusion: The difference lies in the way functions are accessed. With import module, you use module.function(). With from module import function, you use function() directly.

Question 2:

A function checkMain() defined in module Allchecks.py is being used in two different programs:

  • Program 1: Allchecks.checkMain(3, 7)
  • Program 2: checkMain(4, 7)

Why are these two function-call statements different from one another when the function being invoked is just the same?

Answer:

  • In Program 1, the module was imported using: import Allchecks, so function call must be prefixed with module name: Allchecks.checkMain().
  • In Program 2, the module was imported using: from Allchecks import checkMain, so function can be called directly: checkMain().

Conclusion: The import method affects how the function is accessed. Both calls use the same function but in different ways based on how the module was imported.

Question 3:

Given below is semi-complete code of a module basic.py. Complete the code and save it as a module.

"""
This module provides basic math operations like square, multiply, divide, and floor divide.
"""

def square(x):
    """Returns the square of the given number."""
    return mul(x, x)

def mul(x, y):
    """Returns the product of x and y."""
    return x * y

def div(x, y):
    """Returns the floating-point division of x and y."""
    return float(x) / y

def fdiv(x, y):
    """Returns the integer division (floor division) of x and y."""
    return x // y

def floordiv(x, y):
    """Calls the fdiv() function for floor division."""
    return fdiv(x, y)

Explanation:

  • All function definitions are completed and properly indented.
  • Each function includes a docstring for clarity.
  • This file should be saved as basic.py and can be imported in other programs using either of these:
import basic
from basic import square, div

Question 7:

Suppose that after we import the random module, we define the following function called diff() in a Python session:

def diff():  
    x = random.random() - random.random()  
    return x

What would be the result if you now evaluate:

y = diff y()   
print(y)

Output/Error:

SyntaxError: invalid syntax

Explanation:

  • The line y = diff y() is invalid in Python.
  • Function names must be followed directly by parentheses (no space): diff().
  • If you write diff y(), Python interprets it as calling a function named diff with argument y() — but due to the space, it's treated as a syntax error.

Correct Usage:

y = diff()
print(y)

This would output a random float between -1.0 and 1.0.
