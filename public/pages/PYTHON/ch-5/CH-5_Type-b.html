Question 1:

How are the following codes different from one another?

# Code A
my_file = open('poem.txt', 'r')
my_file.read()
# Code B
my_file = open('poem.txt', 'r')

Difference:

  • Code A opens the file in read mode and reads its content using read().
  • Code B only opens the file but does not read anything from it.

So, Code A gives output (file content), Code B does nothing.

Question 3:

Consider the file poemBTH.txt (content given earlier). What output will be produced by the following code?

obj1 = open("poemBTH.txt", "r")
s1 = obj1.readline()
s2 = readline(10)   # Incorrect line!
s3 = obj1.read(15)
print(s3)
print(obj1.readline())
obj1.close()

Output:

  • This code contains an error on the line: s2 = readline(10)
  • readline() must be called with a file object, i.e. obj1.readline(10)
  • Error: NameError: name 'readline' is not defined

Corrected Code:

obj1 = open("poemBTH.txt", "r")
s1 = obj1.readline()          # Reads the first line
s2 = obj1.readline(10)        # Reads next 10 characters from second line
s3 = obj1.read(15)            # Reads next 15 characters
print(s3)
print(obj1.readline())        # Reads next full line
obj1.close()

Explanation: The file cursor moves line-by-line. After fixing, it reads partial lines based on the character count, so actual output depends on the poem’s content.

Question 11:

What will be the output of the following code?

import pickle
ID = {"1":"Ziva","2":"35098","3":"IT","4":"30","5":"Dunzo"}
fin = open("emp.pkl","wb")
pickle.dump(ID, fin)
fin.close()
fout = open("emp.pkl","rb")
ID = pickle.load(fout)
print(ID[5])

Output:

KeyError: 5

Explanation:

  • The dictionary ID has **string keys**, e.g., "1", "2", ..., "5".
  • ID[5] tries to access using an integer key, which **does not exist**.
  • Correct access would be: ID["5"] which gives "Dunzo".
Question 12:

What will be the output of the following code?

import pickle
List1 = ['Roza', {'a': 23, 'b': True}, (1, 2, 3), [['dogs', 'cats'], None]]
List2 = ['Rita', {'x': 45, 'y': False}, (9, 5, 3), [['insects', 'bees'], None]]
with open('data.pkl', 'wb') as f:
    f.write(List1)    # Error here
with open('data.pkl', 'wb') as f:
    f.write(List2)
with open('data.pkl', 'rb') as f:
    List1 = pickle.load(f)
print(List1)

Output:

TypeError: a bytes-like object is required, not 'list'

Explanation:

  • The line f.write(List1) tries to write a list directly to binary file.
  • This is invalid. You must use pickle.dump(List1, f) to serialize.
  • So the code throws TypeError before reaching the print statement.

Correct way:

with open('data.pkl', 'wb') as f:
    pickle.dump(List1, f)

Question 14:

Identify the error in the following code:

import csv  
f = open('attendees1.csv')  
csv_f = csv.writer(f)

Correction:

  • csv.writer(f) is used for writing. But no write operation is being performed in the code.
  • If the intention is to read the file, use csv.reader(f) instead.

Correct version:

import csv  
f = open('attendees1.csv')  
csv_f = csv.reader(f)  
for row in csv_f:  
    print(row)
Question 15:

Identify the error in the following code:

import pickle  
data = ['one', 2, [3, 4, 5]]  
with open('data.dat', 'wb'):  
    pickle.dump(data)

Error Explanation:

  • The open() function inside the with block is incomplete.
  • You must assign the opened file to a variable using as keyword.
  • Otherwise, pickle.dump(data) has no file handle to write into.

Correct version:

import pickle  
data = ['one', 2, [3, 4, 5]]  
with open('data.dat', 'wb') as f:  
    pickle.dump(data, f)
