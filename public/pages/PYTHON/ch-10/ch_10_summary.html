📘 Chapter 10 – Relational Databases (Topics 10.1 to 10.8)

10.1 Introduction (Parichay)

  • Database system ek computer-based record-keeping system hota hai.
  • Database = interrelated data ka sangrah jo multiple applications ko support karta hai.
  • Data programs se independent hota hai.
  • Database allow karta hai:
    • Data retrieval
    • Continuous data modification
    • Querying & searching
  • Decision-making process ke liye essential hota hai.

10.2 Purpose of DBMS (DBMS ka Uddeshya)

  • DBMS ensure karta hai ki data accurate, private & protected ho.
  • Centralized approach file processing system ki problems ko solve karti hai:
    • Data Redundancy (duplicate data)
    • Data Inconsistency
    • Unsharable, unstandardized, insecure data
  • DBMS = Database ko store + maintain + manage karne wala software.
  • Database + DBMS = Database System

10.3 Relational Database Model

  • Data tables (relations) me store hota hai—rows = tuples, columns = attributes.
  • Primary Key har tuple ko uniquely identify karti hai.
  • Example Relations:
    • Suppliers (SuppNo, Supp_Name, Status, City)
    • Items (ItemNo, Item_Name, Price)
    • Shipments (SuppNo, ItemNo, Qty)

10.4 Relational Model Terminology

  • Proposed by E.F. Codd (IBM).
Relation Properties
  • Column values must be of same kind.
  • Values must be atomic.
  • No two rows identical.
  • Row order irrelevant.
  • Column names unique.
Core Definitions
  • Domain: Allowed set of values for a column.
  • Tuple: A row.
  • Attributes: Columns.
  • Degree: No. of attributes.
  • Cardinality: No. of rows.
Views (Virtual Tables)
  • No physical storage.
  • Derived from base tables.
  • Security & restricted access ke liye useful.
Keys
  • Primary Key: Unique, non-null identifier.
  • Composite PK: Multiple columns (SuppNo + ItemNo).
  • Candidate Key: All possible keys.
  • Alternate Key: Candidate key not chosen.
  • Foreign Key: Another table ke PK ko reference karta hai.
Referential Integrity
  • Invalid FK values allowed nahi.
  • Parent record delete nahi hota if child exists.
  • PK change nahi hota if dependencies exist.

10.5 Brief History of MySQL

  • Open-source RDBMS using SQL.
  • Created by Michael Widenius (Monty).
  • Named after his daughter “My”.
  • Dolphin logo name: Sakila.
  • Developed by MySQL AB → acquired by Sun Microsystems.

10.6 MySQL Database System

  • Client/server architecture.
  • Multi-user database system.
  • Supports SQL standards.
  • Key Features:
    • Free (LAMP stack)
    • Very fast + clustering support
    • Strong security
    • Handles millions/billions of rows
    • Runs on many OS
    • CLI + GUI tools available

10.7 Starting MySQL

  • Windows steps:
    • Start → All Programs → MySQL → Command Line Client
    • Password enter karein
    • Prompt: mysql>
    • Exit: quit

10.8 MySQL and SQL

  • SQL = standard language for RDBMS.
  • Developed at IBM San Jose Laboratory.
  • Used for creating, retrieving, updating, transferring data.
10.8.1 SQL Processing Capabilities
  • DDL – Schema define/modify/delete
  • Interactive DML – Query/Insert/Delete/Update
  • Embedded DML – Used inside languages like C/C++
  • Views, integrity, transactions
10.8.2 Data Definition Language (DDL)
  • Creates database schema.
  • Stores info in Data Dictionary (metadata storage).
10.8.3B Data Manipulation Language (DML)
  • Retrieval, insertion, deletion, modification.
  • Procedural & non-procedural types.
  • Commands: INSERT, UPDATE, DELETE.
10.8.3C Transaction Control Language (TCL)
  • COMMIT: Save changes.
  • ROLLBACK: Undo changes.
  • SAVEPOINT: Partial rollback markers.

RDBMS ek bade library system ki tarah hota hai. Tables = Different shelves Primary Key = ISBN Foreign Key = Borrowing slips linking to books SQL = Language used by librarian + visitors to locate/update books Data Dictionary = Library catalog
