Q1. Write a function that takes amount-in-dollars and dollar-to-rupee conversion price, and returns the amount in rupees.
Implement the function in both void and non-void form. 

# Non-void function (returns value)
def convert_to_rupees(dollars, rate):
    return dollars * rate

# Void function (prints value directly)
def print_rupees(dollars, rate):
    print("Converted Amount in Rupees:", dollars * rate)

# Main code
amount = 50
conversion_rate = 83.2

rupees = convert_to_rupees(amount, conversion_rate)
print("Returned Amount in Rupees:", rupees)

print_rupees(amount, conversion_rate)

# Output:
# Returned Amount in Rupees: 4160.0
# Converted Amount in Rupees: 4160.0
Explanation: The first function returns the converted value, while the second function just prints it.
Q2. Write a function to calculate volume of a box using default parameters:
  • (a) length
  • (b) width
  • (c) height
Write a complete program to test it. 

# Function with default parameters
def volume_box(length=1, width=1, height=1):
    return length * width * height

# Main code
print("Default box volume:", volume_box())              # Output: 1
print("Custom box volume:", volume_box(5, 3, 2))        # Output: 30
print("Partial args (length & width):", volume_box(4, 2))  # height defaults to 1 → Output: 8
print("Only length:", volume_box(7))                    # width & height default → Output: 7

# Output:
# Default box volume: 1
# Custom box volume: 30
# Partial args (length & width): 8
# Only length: 7
Explanation: Python allows default values in functions. If fewer arguments are passed, defaults are used.

Q6. Write a function namely nthRoot() that receives two parameters x and n and returns nth root of x i.e., x1/n. The default value of n is 2. 

# Function to compute nth root with default n = 2
def nthRoot(x, n=2):
    return x ** (1/n)

# Test cases
print(nthRoot(25))       # 5.0 (Square root)
print(nthRoot(27, 3))    # 3.0 (Cube root)
print(nthRoot(16, 4))    # 2.0 (Fourth root)

# Output:
# 5.0
# 3.0
# 2.0
Explanation:
  • The operator ** is used to calculate powers and roots in Python.
  • If n is not passed, it defaults to 2, making the function return the square root.
  • The function is flexible and works for any positive integer n.
Q7. Write a function that takes a number n and then returns a randomly generated number having exactly n digits (not starting with zero). 

import random

def generateNDigitNumber(n):
    if n == 1:
        return random.randint(1, 9)
    start = 10**(n-1)
    end = 10**n - 1
    return random.randint(start, end)

# Example calls
print(generateNDigitNumber(2))  # Example: 23
print(generateNDigitNumber(4))  # Example: 1045

# Output (random):
# 23
# 1045
Explanation:
  • 10**(n-1) gives the smallest n-digit number.
  • 10**n - 1 gives the largest n-digit number.
  • Ensures no leading zero because the range starts from a valid minimum.
Q8. Write a function that takes two numbers and returns the number that has minimum one’s digit. 

def minOnesDigit(a, b):
    if a % 10 < b % 10:
        return a
    else:
        return b

# Example calls
print(minOnesDigit(491, 278))  # 491 (1 < 8)
print(minOnesDigit(123, 452))  # 452 (2 < 3)

# Output:
# 491
# 452
Explanation:
  • We extract the one's digit using % 10.
  • The function compares the one’s digit and returns the smaller one’s digit number.
Q9. Write a program that generates a series using a function which takes first and last values of the series and then generates four terms that are equidistant.
Example: for 1 and 7 → 1 3 5 7 

def generateSeries(first, last):
    step = (last - first) // 3
    series = [first + i*step for i in range(4)]
    return series

# Example calls
print(generateSeries(1, 7))    # [1, 3, 5, 7]
print(generateSeries(2, 8))    # [2, 4, 6, 8]

# Output:
# [1, 3, 5, 7]
# [2, 4, 6, 8]
Explanation:
  • The difference between consecutive numbers is calculated as (last - first) // 3.
  • A list comprehension is used to generate exactly four values spaced equally.
