Question 1: What are the errors in the following codes?

(a) Find errors, correct the code, and predict the output:
total = 0;
def sum(arg1, arg2):  
    total = arg1 + arg2;  
    print("Total :", total)  
    return total;  

sum(10, 20);

Errors:

  • Semicolons (;) are not required in Python.
  • Using total inside function creates a local variable; the global total remains 0.

def sum(arg1, arg2):
    total = arg1 + arg2
    print("Total :", total)
    return total

sum(10, 20)
print("Total :", total)  # Will still print 0 because global 'total' was not modified

Total : 30
Total : 0

Question 2: The code below accepts a number and returns its reverse. Fix all syntax and logical errors.
define revNumber(num);
 rev = 0  
 rem = 0  
 While num > 0: 
     rem == num % 10  
     rev = rev * 10 + rem  
     num = num / 10  
     return rev 
print(revNumber(1234))

Errors:

  • define should be def.
  • Semicolons (;) are not required.
  • While should be lowercase: while.
  • rem == num % 10 is a comparison; should be assignment: rem = num % 10.
  • num / 10 does float division. Use integer division: num // 10.
  • Return should be outside the loop to return final reversed number.

Corrected Code:

def revNumber(num):
    rev = 0
    rem = 0
    while num > 0:
        rem = num % 10
        rev = rev * 10 + rem
        num = num // 10
    return rev

print(revNumber(1234))

Output:

4321

Question 8:
a = 10 
y = 5

def myfunct(): 
    y = a
    a = 2 
    print("y =", y, "a =", a)  
    print("a + y =", a + y)  
    return a + y   

print("y =", y, "a =", a)  
print(myfunct())  
print("y =", y, "a =", a)
Output: 
UnboundLocalError: local variable 'a' referenced before assignment
  • Python throws an UnboundLocalError because the variable a is assigned within the function (a = 2), making it a local variable by default.
  • When y = a is executed, it tries to access the local a before it has been assigned — which is not allowed.
  • This error happens before any print() inside myfunct() is executed.

Correct Fix: If you want to use the global variable a inside the function, you must declare it using global a:

def myfunct(): 
    global a
    y = a
    a = 2 
    print("y =", y, "a =", a)  
    print("a + y =", a + y)  
    return a + y

Question 20 (i):
def increment(n):

    return n  

L = [1, 2, 3]  
M = increment(L)  
print(L, M)

[1, 2, 3, [4]] [1, 2, 3, [4]]

Question 20 (ii):
def increment(n):  
    n.append([49])  
    return [n[0], n[1], n[2], n[3]]  

L = [23, 35, 47]  
m1, m2, m3, m4 = increment(L)
print(L)  
print(m1, m2, m3, m4)  
print(L[3] == m4)

Output:

[23, 35, 47, [49]]
23 35 47 [49]
True

Explanation:

  • n.append([49]) adds a nested list [49] to L.
  • return [n[0], n[1], n[2], n[3]] returns the first 4 elements, including the newly added [49].
  • L[3] == m4 returns True because both refer to the same list object [49].
