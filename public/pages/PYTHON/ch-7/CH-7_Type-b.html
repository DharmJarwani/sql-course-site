Q1. Create a list SqLst that stores doubles of elements of NumLst. Will this code work? What will SqLst contain?
NumLst = [1-8]
SqLst = NumLst * 2
• No, this code does NOT double each element.
• The operator * repeats the list, it does not multiply elements.

Correct Output:
SqLst will contain NumLst repeated twice.
Q2. Change the code so SqLst stores doubled values of each element. 

NumLst = [1,2,3,4,5,6,7,8]
SqLst = []

for item in NumLst:
    SqLst.append(item * 2)

# OR using list comprehension:
# SqLst = [item * 2 for item in NumLst]
✔ Uses append() – a linear list insertion operation. ✔ Works correctly for doubling each element.
