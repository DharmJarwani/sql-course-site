📘 Chapter 7 – Type A Assignment Questions (Short Answers)

1. What are data structures? Name some common data structures.

A Data Structure is a named group of data of different types stored in a specific manner so it can be processed as a single unit. Common data structures: Stacks, Queues, Linked Lists, Trees.

2. Is data structure related to a data type? Explain.

Yes, they are related but not the same. • Data Type defines allowed values + operations (e.g., integers cannot have decimals).
• Data Structure defines how data is stored, accessed & manipulated physically (e.g., stack works on LIFO).

3. What do you understand by linear and non-linear data structures?

• Linear Data Structures: Elements arranged sequentially (e.g., Stack, Queue).
• Non-Linear Data Structures: Multi-level arrangement (e.g., Tree).

4. Name some linear data structures. Is linked list a linear data structure?

Linear structures: Stack, Queue, Linked List. Yes, Linked List is a linear data structure.

5. What is the working principle of data structures stack and queues?

• Stack → LIFO (Last In First Out)
• Queue → FIFO (First In First Out)

6. What is a linear list data structure? Name some operations on linear lists.

A Linear List (Array) is a named list of finite, similar elements stored at consecutive positions (0,1,2…n−1). Operations include: Insertion, Deletion, Searching, Traversal, Sorting, Merging.

7. What are data structures? Name some common data structures. (Duplicate)

Same as Q1 — Data Structures include: Stacks, Queues, Linked Lists, Trees.

8. Is data structure related to a data type? Explain. (Duplicate)

Data Type specifies values + operations. Data Structure defines how data is stored & processed physically.

9. What do you understand by linear and non-linear data structures? (Duplicate)

Linear → sequential arrangement. Non-linear → hierarchical arrangement.

10. Name some linear data structures. Is linked list a linear data structure? (Duplicate)

Linear structures: Stack, Queue, Linked List. Yes, Linked List is linear.

11. What are stacks? On which principle do they work?

A Stack is a linear data structure where insertion/deletion occur only at the top. It works on the LIFO (Last In First Out) principle.

12. What are push and pop operations?

• PUSH → add new data to top of stack.
• POP → remove data from top of stack.

13. Give some examples of stack applications.

• Reversing a line • Converting infix expressions into prefix/postfix (Polish Notation)

14. What is the order in which operations are performed in a stack?

Operations follow the LIFO (Last In First Out) order.
