# Read the limit
limit = float(input("Enter the limit"))
max_price = 0

# Read the next price
next_price = float(input("Enter a price or 0 to stop:"))

while next_price > 0:
    if next_price < limit and next_price > max_price:
        max_price = next_price
    next_price = float(input("Enter a price or 0 to stop:"))

if max_price > 0:
    print("Largest price less than limit:", max_price)
else:
    print("No valid price found.")

3. Which of the following is the correct output for the execution of the following Python statement?

print(5 + 3 ** 2 / 2)
Correct Answer: (b) 8.0
Explanation: According to operator precedence:
3 ** 2 = 9
9 / 2 = 4.5
5 + 4.5 = 8.0

6. Is the loop in the code below infinite? How do you know (for sure) before you run it?

m = 3
n = 5  
while n < 10:  
    m = n - 1  
    n = 2 * n - m  
    print(n, m)
Answer: No, this loop is not infinite.

Explanation:
  • Start: m = 3, n = 5
  • 1st iteration: m = 4, n = 6
  • 2nd: m = 5, n = 7
  • 3rd: m = 6, n = 8
  • 4th: m = 7, n = 9
  • 5th: m = 8, n = 10 (loop ends)
So, it executes 5 times and stops when n becomes 10.
