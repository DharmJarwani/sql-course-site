Question 1: What are tokens in Python? How many types of tokens are allowed in Python? Exemplify your answer.

Tokens are the smallest units in a Python program. Python has five types of tokens:

  • Keywords – e.g. if, else, while
  • Identifiers – names like x, total_sum
  • Literals – values like 10, "Hello"
  • Operators – like +, -, *, /
  • Separators – like ( ), { }, [ ], : ,
Question 2: How are keywords different from identifiers?

Keywords are reserved words in Python used for specific functionalities (e.g. if, def, return), and cannot be used as variable names.

Identifiers are names given to variables, functions, classes etc., and are defined by the user.

Question 3: What are literals in Python? How many types of literals are allowed in Python?

Literals are data items that have a fixed value. Python supports:

  • String Literals – e.g. "Hello"
  • Numeric Literals – e.g. 10, 3.14
  • Boolean Literals – True, False
  • Special Literal – None
  • Collection Literals – [ ], { }, ( )
Question 4: State True or False: “Variable declaration is implicit in Python.”

Question 11: What are operators? What is their function? Give examples of some unary and binary operators.

Operators are special symbols in Python used to perform operations on variables and values.

Unary Operators: operate on a single operand. Example: -a, not x

Binary Operators: operate on two operands. Example: a + b, x and y

Question 13: What is an expression and a statement?

Expression: A combination of variables, operators, and values that returns a result.
Example: a + 5

Statement: A complete instruction that performs an action.
Example: print("Hello")

Question 17: Describe the concepts of block and body. What is indentation and how is it related to block and body?

A block is a group of statements meant to be executed together.

The body refers to the internal code of constructs like functions, loops, or if-statements.

Indentation in Python is used to define a block. All lines in a block must have the same level of indentation.

Question 18: (a) What are data types? How are they important?
Write the names of any four data types available in Python.

Data types define the kind of value a variable holds. They are important to perform correct operations and save memory efficiently.

Examples: int, float, str, bool

Question 19: How many integer types are supported by Python? Name them.

Python supports a single int type for integers (no limit on size as in other languages).

However, integers can be classified into:

  • Decimal (e.g. 25)
  • Binary (e.g. 0b110)
  • Octal (e.g. 0o10)
  • Hexadecimal (e.g. 0xFF)
Question 20: What are immutable and mutable types? List immutable and mutable types of Python.

Immutable types: Cannot be changed after creation.
Examples: int, float, str, tuple, bool

Mutable types: Can be modified after creation.
Examples: list, dict, set, bytearray

Question 21: What is the difference between implicit type conversion and explicit type conversion?
  • Implicit Type Conversion: Done automatically by Python when it converts one data type to another without user involvement.
  • Explicit Type Conversion: Done manually by the programmer using type conversion functions like int(), float(), str() etc.
Question 22: An immutable data type is one that cannot change after being created. Give three reasons to use immutable data.
  • They are hashable and can be used as keys in dictionaries.
  • They ensure data integrity by avoiding accidental changes.
  • They are thread-safe and useful in concurrent programming.
Question 23: What is an Entry Controlled Loop? Which loop is entry controlled in Python?

An entry controlled loop checks the condition before entering the loop body. If the condition is false initially, the loop does not execute at all.

  • while loop is an entry-controlled loop
  • for loop is also considered entry-controlled as it checks condition before each iteration
Note: Code explanation below is just for your understanding.
x = 1
while x <= 3:
    print("x =", x)
    x += 1
# Output:
# x = 1
# x = 2
# x = 3
Question 24: Explain the use of the pass statement. Illustrate it with an example.

The pass statement is used as a placeholder in Python where a statement is syntactically required but no action is needed. It prevents syntax errors.

Note: Code explanation below is just for your understanding.
for i in range(5):
    if i == 3:
        pass  # placeholder for future code
    else:
        print(i)
# Output:
# 0
# 1
# 2
# 4
