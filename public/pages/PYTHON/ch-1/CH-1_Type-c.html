Q1. Write a program to print one of the words negative, zero, or positive, according to whether variable x is less than zero, zero, or greater than zero, respectively. 

# Program to check if a number is negative, zero or positive

# Taking input from user
x = int(input("Enter a number: "))

# Checking conditions
if x < 0:
    print("negative")
elif x == 0:
    print("zero")
else:
    print("positive")

# Output:
# If user enters -5 → negative
# If user enters 0  → zero
# If user enters 7  → positive
Explanation:
  • User enters a number which is stored in x.
  • if, elif, else statements check whether it is less than, equal to, or greater than zero.
  • This is a basic decision-making program using conditional logic.
Q2. Write a program that returns True if the input number is an even number, False otherwise. 

# Program to check if a number is even

num = int(input("Enter a number: "))

# Return True if even, else False
if num % 2 == 0:
    print(True)
else:
    print(False)

# Sample Output:
# If input is 8 → True
# If input is 5 → False
Explanation:
  • num % 2 gives remainder after dividing by 2.
  • If remainder is 0, number is even → return True.
  • Otherwise, it's odd → return False.
Q3. Write a Python program that calculates and prints the number of seconds in a year. 

# Calculate number of seconds in a year

days = 365
hours = 24
minutes = 60
seconds = 60

total_seconds = days * hours * minutes * seconds
print("Seconds in a year:", total_seconds)

# Output: Seconds in a year: 31536000
Explanation:
  • 1 day = 24 × 60 × 60 = 86400 seconds
  • 365 days = 365 × 86400 = 31536000 seconds
  • This program does not account for leap year (extra day).

daynum = int(input("Enter day number (2-365): "))
first = input("Enter first day of year: ")

days = ["Sunday", "Monday", "Tuesday", "Wednesday", "Thrusday", "Friday", "Saturday"]

if first in days:
    first_index = days.index(first)
    day_index = (first_index + daynum - 1) % 7
    print("Day on that date is:", days[day_index])
else:
    print("Invalid first day input")

# Sample:
# daynum = 3, first = Wednesday → Wednesday + 2 = Friday
# Output: Day on that date is: Friday
Explanation:
  • Finds index of first day in list.
  • Adds day number offset and uses modulo 7 to wrap around.
  • Handles invalid input for day name.

Q7. Write a program that prints the sum from N to 2N if N is positive, or from 2N to N if N is negative. 

N = int(input("Enter an integer N: "))
total = 0

if N >= 0:
    for i in range(N, 2*N + 1):
        total += i
else:
    for i in range(2*N, N + 1):
        total += i

print("Sum is:", total)

# Sample:
# If N = 3 → sum = 3+4+5+6 = 18
# If N = -3 → sum = -6 + -5 + -4 + -3 = -18
Explanation:
  • If N is positive: range from N to 2N.
  • If N is negative: range from 2N to N (ascending).
  • Accumulates the total using a loop.

Q11. Write a program that reads two times in military format (0900, 1730) and prints the number of hours and minutes between the two times. A sample run is being given below :

Please enter the first time : 0900
Please enter the second time : 1730
8 hours 30 minutes 

# Program to find difference between two military times

# Read first time (like 0900 or 1730)
t1 = int(input("Please enter the first time : "))
t2 = int(input("Please enter the second time : "))

# Convert each time into minutes
h1 = t1 // 100
m1 = t1 % 100
total1 = h1 * 60 + m1

h2 = t2 // 100
m2 = t2 % 100
total2 = h2 * 60 + m2

# Find difference in minutes
diff = abs(total2 - total1)

# Convert back to hours and minutes
hours = diff // 60
minutes = diff % 60

print(hours, "hours", minutes, "minutes")

# Sample Output:
# Please enter the first time : 0900
# Please enter the second time : 1730
# 8 hours 30 minutes
Explanation:
  • Input times are given in military format e.g., 0900, 1730.
  • Split into hours and minutes using // and %.
  • Convert both times into total minutes so subtraction becomes easy.
  • abs(total2 - total1) gives a positive difference even if user enters times in reverse.
  • Convert minutes difference back into hours and minutes.
ABS() Function Meaning:
  • abs(x) returns the positive value of any number.
  • Example: abs(4 - 10) = -6 and abs(10 - 4) = 6.
