2. Differentiate between CHAR and VARCHAR datatypes.

Solution:

Difference:
CHAR = Fixed-length string.
VARCHAR = Variable-length string.

CHAR(n) → Always stores exactly n bytes. If value shorter → MySQL adds blank spaces.

VARCHAR(n) → Stores only actual characters (no padding). If length > n → Error is shown.

21. Differentiate between COUNT(*) and COUNT(column) functions in SQL with example.

Solution:

COUNT(*) → Returns the count of all rows in the table (including NULLs).
COUNT(column) → Counts only non-NULL values of that column.

26. Display employees hired between May 20, 1990 and Dec 31, 1991 (ordered by HireDate)

Query:

SELECT ename, job, sal, hiredate
FROM empl
WHERE hiredate BETWEEN '1990-05-20' AND '1991-12-31'
ORDER BY hiredate;

Explanation:
This query shows:
✔ Employee Name
✔ Job
✔ Salary
✔ HireDate

Only those employees are included whose hiredate falls within the given range, and results are shown in ascending order of hiredate.

27. Display employee name and total number of years passed since HireDate

Query:

SELECT ename, YEAR(CURDATE()) - YEAR(hiredate)
FROM empl;

Explanation:
✔ YEAR(CURDATE()) → current year
✔ YEAR(hiredate) → year employee was hired
✔ Difference gives total years completed in service.

NOTE: The calculated result ignores months/days and only shows difference in years.
