Q1. Write a program to validate a phone number in the format xxx-xxx-xxxx. Dashes should be at correct positions and rest must be digits. 

phone = input("Enter phone number (xxx-xxx-xxxx): ")

if len(phone) == 12 and phone[3] == '-' and phone[7] == '-' and phone.replace('-', '').isdigit():
    print("VALID phone number.")
else:
    print("INVALID phone number.")

# Sample Output:
# Enter phone number (xxx-xxx-xxxx): 017-555-1212
# VALID phone number.
Explanation:
  • Checks length = 12.
  • Ensures dashes are at 4th and 8th positions.
  • Ensures other characters are digits using replace('-', '').isdigit().
Q2. Write a program to accept a sentence and print: number of words, characters, and percentage of alphanumeric characters. 

sentence = input("Enter a sentence: ")

words = sentence.split()
num_words = len(words)
num_char = len(sentence)
alnum_count = 0

for ch in sentence:
    if ch.isalnum():
        alnum_count += 1

percentage = (alnum_count / num_char) * 100

print("Original sentence: ", sentence)
print("Number of words: ", num_words)
print("Number of characters: ", num_char)
print("Percentage of alphanumeric characters: ", percentage)

# Sample Output:
# Enter a sentence: Hello World 123!
# Number of words: 3
# Number of characters: 17
# Percentage of alphanumeric characters: 82.35
Explanation:
  • split() breaks the sentence into words.
  • isalnum() checks for letters and digits.
  • Alphanumeric % = (alnum chars / total chars) × 100
Q3. Write a program that adds two lists element-wise to form a third list. Example: If L = [3,1,4] and M = [1,5,9], output N = [4,6,13] 

L = [3, 1, 4]
M = [1, 5, 9]
N = []

for i in range(len(L)):
    N.append(L[i] + M[i])

print("New list N: ", N)

# Output:
# New list N: [4, 6, 13]
Explanation:
  • range(len(L)) loops through index of both lists.
  • L[i] + M[i] adds elements at same index.
  • append() builds the result list N.
Q4. Write a program that rotates the elements of a list to the right. Last element should move to first position. 

L = [10, 20, 30, 40]

last = L[-1]
for i in range(len(L) - 1, 0, -1):
    L[i] = L[i - 1]
L[0] = last

print("Rotated list: ", L)

# Output:
# Rotated list: [40, 10, 20, 30]
Explanation:
  • Save last element.
  • Shift other elements to right by 1 position.
  • Assign last element to position 0.
Q5. Write a short code segment that prints the longest word in a list of words. 

words = ['apple', 'banana', 'grape', 'watermelon']
longest = words[0]

for word in words:
    if len(word) > len(longest):
        longest = word

print("Longest word: ", longest)

# Output:
# Longest word: watermelon
Explanation:
  • Start by assuming first word is the longest.
  • Loop through the list and compare lengths using len().
  • Update longest if a longer word is found.

Q8. Write a Python program to create a tuple storing the first 9 Fibonacci numbers. 

fibo = [0, 1]

for i in range(2, 9):
    fibo.append(fibo[i - 1] + fibo[i - 2])

fibo_tuple = tuple(fibo)
print("First 9 Fibonacci numbers: ", fibo_tuple)

# Output:
# First 9 Fibonacci numbers: (0, 1, 1, 2, 3, 5, 8, 13, 21)
Explanation:
  • Fibonacci starts with 0, 1.
  • Next number is sum of previous two.
  • List is converted to tuple using tuple().
Q9. Create a dictionary whose keys are month names and values are number of days. Perform the following:
  • (a) Ask the user to enter a month name and display number of days
  • (b) Print all keys in alphabetical order
  • (c) Print months with 31 days
  • (d) Sort and print month-day pairs by number of days

months = {
    "January": 31, "February": 28, "March": 31, "April": 30,
    "May": 31, "June": 30, "July": 31, "August": 31,
    "September": 30, "October": 31, "November": 30, "December": 31
}

# (a)
name = input("Enter month name: ")
print("Days in", name, "are:", months.get(name, "Invalid month"))
# Input: March
# Output: Days in March are: 31

# (b)
for key in sorted(months):
    print(key)
# Output: Alphabetically sorted month names

# (c)
print("Months with 31 days:")
for key in months:
    if months[key] == 31:
        print(key)
# Output: January, March, May, July, August, October, December

# (d)
sorted_months = sorted(months.items(), key=lambda x: x[1])
for item in sorted_months:
    print(item[0], ":", item[1])
# Output: Months sorted by number of days (ascending)
Explanation: The dictionary holds month-day mappings. Various dictionary and loop operations are used for different outputs.
Q10. Write a function addDict(dict1, dict2) that returns the union of two dictionaries. 

def addDict(dict1, dict2):
    result = dict1.copy()
    result.update(dict2)
    return result

# Main code
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}
print(addDict(d1, d2))
# Output: {'a': 1, 'b': 3, 'c': 4}
Explanation: Dictionary d1 is copied and updated with d2. If a key is repeated, d2's value is used.
Q11. Write a program to sort a dictionary's keys using Bubble Sort. 

d = {"b": 2, "a": 1, "c": 3}
keys = list(d.keys())
n = len(keys)

for i in range(n):
    for j in range(0, n - i - 1):
        if keys[j] > keys[j + 1]:
            keys[j], keys[j + 1] = keys[j + 1], keys[j]

print("Sorted keys:", keys)
# Output: ['a', 'b', 'c']
Explanation: Bubble Sort is applied to list of keys from the dictionary.
Q12. Write a program to sort dictionary values using Bubble Sort. 

d = {"b": 2, "a": 1, "c": 3}
values = list(d.values())
n = len(values)

for i in range(n):
    for j in range(n - i - 1):
        if values[j] > values[j + 1]:
            values[j], values[j + 1] = values[j + 1], values[j]

print("Sorted values:", values)
# Output: [1, 2, 3]
Explanation: List of values is sorted using bubble sort. Keys are not preserved in sorted form.
