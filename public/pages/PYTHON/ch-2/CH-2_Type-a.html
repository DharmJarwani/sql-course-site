Question 1: What is the internal structure of Python strings?

Python strings are sequences of Unicode characters. Internally, a string is stored as an array of characters where each character has a fixed index starting from 0. Strings in Python are immutable, meaning once created, they cannot be changed.

Question 3: Discuss the utility and significance of Lists, briefly.

Lists in Python are used to store multiple values in a single variable. They are ordered, changeable (mutable), and allow duplicate values. Lists are useful for collecting, storing, and processing data like numbers, names, or even mixed types in one place.

Question 4: What do you understand by mutability? What does “in place” task mean?

Mutability means an object can be changed after it's created. Lists in Python are mutable — we can add, remove, or change items.

An "in place" task means the operation changes the existing object directly without creating a new one. For example, list.sort() sorts the list in place.


numbers = [3, 1, 4]
numbers.sort()   # changes the original list
print(numbers)
      
[1, 3, 4]
Question 5: Start with the list [8, 9, 10]. Do the following:

(a) Set the second entry (index 1) to 17.

(b) Remove the first entry from the list.

(c) Double the list.

(d) Add 4, 5 and 6 to the end of the list.

(e) Sort the list.

(f) Insert 25 at index 3.


nums = [8, 9, 10]
nums[1] = 17           # Step (a)
nums.pop(0)            # Step (b)
nums = nums * 2        # Step (c)
nums.extend([4, 5, 6]) # Step (d)
nums.sort()            # Step (e)
nums.insert(3, 25)     # Step (f)
print(nums)
    
[4, 5, 6, 25, 10, 10, 17, 17]

Explanation: Each step changes the list. Final output is sorted and modified as per all given steps. List methods like pop(), extend(), sort(), and insert() are used.

Question 6: What’s a[1:1] if a is a string of at least two characters? And what if string is shorter?

a[1:1] means: slice starting and ending at index 1. It returns an empty string '', regardless of string length, because no characters lie between index 1 and 1.


a = "Hi"
print(a[1:1])   # Output: ''

Even if string has fewer than 2 characters, slicing like a[1:1] is safe and just returns ''.

Question 7: What are the two ways to add something to a list? How are they different?
  • append(): Adds a single element to the end of the list.
  • extend(): Adds elements from another iterable (like list, tuple) to the list.

a = [1, 2]
a.append(3)      # [1, 2, 3]
a.extend([4, 5]) # [1, 2, 3, 4, 5]
print(a)
    
[1, 2, 3, 4, 5]
Question 8: What are the two ways to remove something from a list? How are they different?
  • remove(value): Removes the first occurrence of the given value.
  • pop(index): Removes the item at the given index and returns it. If index is not given, removes the last item.

a = [10, 20, 30, 20]
a.remove(20)  # removes first 20
a.pop()       # removes last item (30)
print(a)
    
[10, 30]

Question 11: Discuss the utility and significance of Tuples, briefly.

Tuples are similar to lists, but they are immutable — once created, their values cannot be changed. This makes them useful for:

  • Storing fixed data (like coordinates or days of week)
  • Using as keys in dictionaries (lists cannot be used)
  • Protecting data from accidental changes

Question 15: Why is a dictionary termed as an unordered collection of objects?

In a dictionary, values are stored using key–value pairs. The order in which these pairs are stored is not guaranteed, especially in older versions of Python (before 3.7).

So, even if you add items in a specific order, they may not appear in that order when you print the dictionary. This is why dictionaries are called unordered.

Question 16: What type of objects can be used as keys in dictionaries?

Only immutable types can be used as dictionary keys — such as:

  • Strings ('name')
  • Numbers (1, 2.5)
  • Tuples (if they contain only immutable items)

Mutable types like lists or dictionaries cannot be used as keys.

Question 17: Though tuples are immutable types, yet they cannot always be used as keys in a dictionary. What is the condition to use tuples as a key in a dictionary?

Tuples can be used as keys only if they contain immutable elements inside them.

If a tuple contains a list or another mutable object, it cannot be used as a key.


t1 = (1, 2)            # Valid key
t2 = ([1, 2], 3)       # Invalid key (contains list)

Question 19: How is del D and del D[<key>] different if D is a dictionary?
  • del D deletes the entire dictionary.
  • del D['key'] deletes only the key–value pair for the given key.

D = {'a': 1, 'b': 2}
del D['a']   # removes only key 'a'
del D        # removes the whole dictionary

Question 22: Discuss Bubble Sort and Insertion Sort techniques.

Bubble Sort: Compares adjacent elements and swaps if needed. Largest elements "bubble" to the end in each pass.

Insertion Sort: Builds the sorted list by inserting one element at a time into its correct position.


# Bubble Sort example
a = [5, 2, 9, 1]
n = len(a)
for i in range(n):
    for j in range(0, n-i-1):
        if a[j] > a[j+1]:
            a[j], a[j+1] = a[j+1], a[j]
print(a)  # [1, 2, 5, 9]
